# Zingen — Landing Page de Produto

Atividade prática de Front-End: landing page responsiva desenvolvida com **HTML5 e CSS3**, sem frameworks e sem JavaScript.

## Executar

Abra `index.html` no navegador. Não é necessário instalar dependências. As imagens, ícones e a fonte estão dentro de `assets`, permitindo abrir a página sem internet.

## Estrutura

- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: estilos, tokens de cores, Flexbox, Grid e media queries.
- `assets/`: imagens, ícones e fonte Inter local.
- `entrega/`: ZIP do projeto, quando gerado.

## Responsividade

Layout fluido com ajustes em 1050px (tablet), 760px (mobile) e 360px (celulares pequenos). As grades de funcionalidades e planos passam para uma coluna no celular. As imagens são flexíveis e os links principais continuam disponíveis no conteúdo e no rodapé.
